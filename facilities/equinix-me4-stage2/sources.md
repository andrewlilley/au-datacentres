# Sources: equinix-me4-stage2

Access date for all: 2026-09-27. Sources marked "(snippet only)" were seen only in web-search result snippets; all others were read in full.

1. Icon, 'Metronode Derrimut MEL-2 Expansion Stage 2' project page. https://icon.co/projects/metronode-derrimut-mel-2-expansion-stage-2/ (accessed 2026-09-27). Supports: client Metronode; design & construction of a data centre; ultimate designed capacity 18 MW, 7.6 MW installed; completion September 2017; duration 12 months; value $62 million; scope (ten high-density data halls fitted out, shell for two more, two POP rooms, offices, loading dock, car parking, site-wide services, external works); Icon's third Metronode project at Derrimut.
